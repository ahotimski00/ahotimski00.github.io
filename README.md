# Al Hotimski

Geospatial Data Scientist at [The Conservation Fund](https://www.conservationfund.org/). I build data systems and analytical models for land intelligence: ownership tracking, conservation screening, and remote sensing workflows.

**Portfolio:** [ahotimski00.github.io](https://ahotimski00.github.io)

## What I work on

- Automated pipelines for tax parcel ownership tracking and boundary change detection across U.S. timberland — fuzzy entity resolution, LLC hierarchy mapping, spatial overlay analysis
- USDA NRCS ACEP easement eligibility screening at regional scale (Python / ArcGIS Pro)
- Land cover classification and change detection using Google Earth Engine, Landsat, and Random Forest
- Salesforce + ArcGIS Online integration for conservation project spatial workflows
